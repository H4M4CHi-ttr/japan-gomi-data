# 米子市（令和8年度）

公式の24 PDFから30地区の2026-04-01〜2027-03-31を収録する。24 PDFの単位をcourseとして保持し、別地区の同じ日程を勝手に統合しない。

一次ソースは[公式カレンダー](https://www.city.yonago.lg.jp/item/60812.htm)（掲載2026-02-26）、地区対応は[公式町名一覧](https://www.city.yonago.lg.jp/47585.htm)（掲載2026-01-21）。未公開の次年度を外挿しない。第三者アプリは使わない。

```sh
npm ci
node tools/pdf-extractor/yonago/fetch.mjs
node tools/pdf-extractor/yonago/fetch-yomi.mjs
EXTRACTED_AT=2026-10-13 node tools/pdf-extractor/yonago/build.mjs
node tools/pdf-extractor/yonago/verify.mjs
node --test tools/pdf-extractor/yonago/parse.test.mjs
# ファイルを指定してcommitした後
npm run regen -- yonago
npm test
npm run build:ics
```

`findPython(['pdfplumber'])`で処理系を選ぶ。必要なら`PYTHON`へ処理系のパスを渡す。PDFの画像表示はpdfplumber/pypdfium2で実施した。Pythonからの日本語出力には`PYTHONIOENCODING=utf-8`を渡す。ABR取得の共通ライブラリには`unzip`が必要。

生成器はcourse YAML、`coverage.md`（全地区・公式町名表157行の対応）、`exceptions.md`（通常曜日表とPDFの日付集合の203相違）、`sources.json`（取得日・全PDF URL・SHA-256）を書き出す。`meta.yaml`、`taxonomy.yaml`、`survey.yaml`は手書きの正典。キャッシュ、PDF、レンダー画像は追跡しない。

PDFは13ページ（表紙と月別12ページ）でテキスト層があるが、通常の`find_tables()`は数字や塗り矩形の辺を日付罫線として誤認する。外枠と同色の実罫線だけで7列×5段を復元する。日番号のフォントと曜日・全日付集合を確認し、文字の座標から品目を読む。各月の2日が同居する斜め分割セルは、次の日番号の上端までを1日分とする。大和の8月1日は丸印と小さい品目文字が別行にあり、欠落させない。日付欄には健康イベントの時刻が品目の間へ入る場合があるため、品目のフォントを検査して取り分ける。2列にまたがる「収集はありません」の帯も扱う。未知の品目・フォント・日番号・罫線・地区は例外として停止する。

`classifyRules`で規則を導き、`expandRange` / `diffRange`で24×365=8,760日枠を自己検証する。種別別イベントは6,504件。資源・不燃などは原則`monthly_specific`で実日付を保持し、祝日や年末年始を通常規則から生成しない。白色発泡スチロール・トレーを`plastic`、不燃性粗大ごみを`oversized`として限定表示する。缶・ビン類は既存語彙2種に分け、電池類・蛍光管等は`hazardous`。語彙・スキーマに変更はない。

目視は全24 PDFの2027年1月、啓成4月・5月・8月、大和6月・8月、成実・尚徳9月、淀江4月の画像を確認した。`verify.mjs`は各カレンダーの1月1〜2日と4〜9日、祝日・四半期収集・斜め分割・時刻混入の追加サンプルを218日枠として固定保持する。欠落と余分な日付の両方を検出できることも改竄検査で確認する。

独立した公式の全実日付ソースは確認していない。HTMLは通常曜日の独立表現であり、例外日の正典はPDF。目視は選択サンプルで全セルではない。日枠8,760を独立試行数として誤り率を主張しない。

Windowsでは上流の`build-stats.mjs`がURLのpathnameをそのまま使い、`C:\C:\...`となって統計生成に失敗する。米子市の変更によるものではなく、共通スクリプトは変更していない。`build-ics.mjs`単独では全1,000コース（米子24を含む）を生成できる。Linuxの既存CIでも確認する。

公式町名表は239町丁目を259候補に展開した。複数地区にまたがる17町丁目では境界を推測せず、地区名と確認が必要なnoteを保持する。ABRの240町字のうち日ノ出町と米原の丁目なし町字、みのり町は収集一覧に直接現れない。日ノ出町・米原の丁目は収録済みだが、丁目なし町字とみのり町には地区を割り当てない。公式表の全行収録を住所全体の確定と混同しない。
